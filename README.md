# 💰 Expense Tracker

A modern expense tracking web application built with **Flask** and **SQLite** that helps users manage daily expenses efficiently through a clean and responsive interface.

---

## ✨ Features

- ➕ Add Expenses
- ✏ Edit Expenses
- 🗑 Delete Expenses
- 📋 View All Expenses
- 💵 Track Amounts
- 📅 Store Expense Records
- 💾 SQLite Database
- ⚡ Flash Messages
- 🎨 Responsive User Interface

---

## 🛠 Tech Stack

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Artik-r/expense-tracker.git
```

Move into the project

```bash
cd expense-tracker
```

Install dependencies

```bash
pip install -r requirements.txt
```

Initialize the database

```bash
python init_db.py
```

Run the application

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000
```
