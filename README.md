# Expense Tracker

## Overview
A command-line Expense Tracker built with Python that allows users to manage daily expenses using CSV file storage.

## Features
- Add Expense
- View Expenses
- Search Expenses
- Delete Expenses
- Monthly Summary
- Total Spending Dashboard

## Technologies
- Python 3
- CSV
- Datetime
- OS Module

## Project Structure
expense-tracker/
├── main.py
├── expenses.csv
├── README.md
├── requirements.txt
└── .gitignore

## How to Run

python main.py
